# Cozy Furniture — React + Vite

## Run it
1. Install Node.js (v18+): https://nodejs.org
2. In this folder, open a terminal and run:
   npm install
   npm run dev
3. Open the link shown (usually http://localhost:5175).

## Build for hosting
   npm run build   (output goes to /dist; upload to Netlify, Vercel or GitHub Pages)

## Customise
- Add/edit products: src/data.js (put photos in public/images and set `photo`)
- Colours: variables at the top of src/index.css
- Showroom, email: src/App.jsx (search "Hawassa" and "hello@cozyfurniture.et")
- Fonts (free, Google Fonts): Playfair Display, Lora, Special Elite
